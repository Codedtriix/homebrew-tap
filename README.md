# Codedtriix Homebrew Tap

Official Homebrew tap for [Codedtriix](https://codedtrix.in) applications and developer tools.

## Installation

### SkyRemind

A cross-platform reminder companion with animated origami paper airplane alerts in a Notion Dark + Amber theme.

```bash
brew install --no-quarantine Codedtriix/tap/skyremind
```

Or tap first:

```bash
brew tap Codedtriix/tap
brew trust Codedtriix/tap
brew install --cask skyremind
```
